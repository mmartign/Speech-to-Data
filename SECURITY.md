# Security Policy

## Supported Versions

This project is under active development on the `main` branch. Only the
latest commit on `main` is supported with security fixes.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report it privately by emailing
**Maurizio.Martignano@spazioit.com** with:

* A description of the vulnerability and its potential impact
* Steps to reproduce, or a proof of concept if available
* Any relevant logs, configuration, or environment details

You should expect an initial response within a few business days. We'll
work with you to understand and validate the issue, and to coordinate
disclosure once a fix is available.

Given that this project processes speech and medical data (e.g. FHIR
resources), please take particular care when reporting issues that could
involve exposure of sensitive patient information — avoid including real
patient data in reports and reproduction steps.
